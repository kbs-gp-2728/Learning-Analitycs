# Learning Analytics: Patrones temporales de interacción en Open edX

Aplicación para procesar eventos de Open edX y explorar patrones temporales de interacción en cursos virtuales.

> Los indicadores de actividad **no se interpretan automáticamente como aprendizaje o rendimiento**.

## Descripción

Proyecto del Practicum 2.1 que procesa eventos de Open edX y los convierte en visualizaciones y métricas para explorar cómo y cuándo se interactúa con un curso virtual. Trabaja únicamente con datos sintéticos o autorizados y seudonimizados.

## Objetivos

- Procesar y normalizar eventos de Open edX.
- Explorar patrones temporales de interacción (hora, día, semana, sesión).
- Garantizar la seudonimización de los datos.

## Datos y privacidad

- Se usan datos sintéticos o autorizados y seudonimizados.
- No se incluyen datos reales en este repositorio.
